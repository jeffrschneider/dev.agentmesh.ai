The agent lifecycle

AgentMesh builds and runs agents by the agentic development lifecycle, which is published at agenticdevelopment.ai. That site lists every stage from deciding what an agent should do to retiring it. For each stage it names the role, the AgentMesh agent that holds it today, and what the stage hands to the next one.
