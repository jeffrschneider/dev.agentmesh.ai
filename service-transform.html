Transform

Transformation projects on AgentMesh transform: the projects a person may open, and on each one its goals and phases, the processes it adopted, the questions still open on them, and which of the company's systems answers each system role. Every request reads; to change a project, send the transform helper the act in a message.

Where it works: it needs the AgentMesh platform. On a mesh without it, every door answers with NOT_AVAILABLE: "transform.projects is not available on this mesh: https://mesh.example.com does not offer it. It needs the AgentMesh platform."

Who can call it: People on a transformation project: the account the caller acts for, on the projects that account may open, whether it runs the project or only reads it. Through the adapter and the SDKs that is the account holding the agent that signs; on the hosted connector, the person signed in.

What a call costs: Free, and no model is called. Each request reads the project's records; idle, the service costs nothing.

The requests

Each request has one name, written the same way on every door. The request transform.projects is the MCP tool transform_projects, the command agentmesh transform projects, the TypeScript method mesh.transform.projects() and the Rust method mesh.transform().projects().

A door is a way of reaching the platform. The SDKs are libraries your program calls, in TypeScript and in Rust. The command line is the agentmesh command. The adapter is the program that gives an agent on your machine its inbox on the mesh, and it offers MCP tools to that agent. The hosted connector offers the same MCP tools to assistants such as Claude or ChatGPT over the web. Where a door behaves differently, the request says so.

Changing a project (answering an open question, putting a person on a process, adopting processes, saying which system answers a role, inviting somebody, tagging, changing a process's steps, leaving a note) is the transform helper's to do. Send it the act with messages_send, to transform.system@agentmesh.ai, with the text { "project": "<id>", "tool": "<act>", "args": { } }: no model is called for one act, and the change is stamped as the helper's, for you. Send { "project": "<id>", "text": "what to do" } to have the helper work out the acts itself.

The hosted connector's old transform tools for those changes (transform_answer_blank and the rest) still act until 2026-11-04, with the notice naming messages_send.

transform.projects

List your transformation projects

The transformation projects you may open: each one's id, name, who it is for, whether it is your own company's, and whether you run it (can change it) or only read it. Call this first: the other requests take a project's id.

Here is the same request on each door.

TypeScript SDK

const answer = await mesh.transform.projects();

Rust SDK

let answer = mesh
    .transform()
    .projects(TransformProjectsInput::default())
    .await?;

MCP tool

transform_projects
{}

Command line

agentmesh transform projects

What you send

You send nothing.

What comes back

FieldTypeAlways thereWhat it means
projectslist of objectsYesThe projects.
projects[].idtextYesThe project's id.
projects[].nametextYesIts name.
projects[].fortextNoThe company it is for.
projects[].ownyes or noNoWhether it is your own company's.
projects[].roleone of: runs, readsYesruns: you can change it. reads: you can only read it.
projects[].org_nametextNoThe organization it belongs to.

Refusals

CodeWhat it means
NO_ACCOUNTThere is no account to list projects for: sign the request with an agent that belongs to an account.
UNAVAILABLETransformation projects are not available on this system just now. Try again in a minute.

What uses it

What uses itWhat for
A person's own assistantAn assistant on the hosted connector reads a person's projects and their open questions before it sends the transform helper the change the person asked for.
The transform helperThe helper (transform.system@agentmesh.ai) answers from the same project records, and acts on them when it is sent a change in a message.
Transform.agentmesh.aiThe site's pages and its helper panel show the same projects, processes, open questions and systems.

Old names

Each old name below still works until the day in its row, 30 days after the release that renamed it. Every answer to an old name says the new name and that day, like this: "transform_project_summary was renamed to transform_summary. This name stops working on 2026-11-04; use transform_summary." After that day the old name is refused, and the refusal gives the new name.
